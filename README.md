# Agüita 💧

Una web interactiva en español para aprender sobre hidratación y acompañar el hábito de tomar agua, un vaso a la vez.

## Abrir la web

[Visitar Agüita](https://martnmartnez14.github.io/aguita/)

## Qué incluye

- Guía orientativa sobre líquidos diarios, basada en información de [Mayo Clinic](https://www.mayoclinic.org/es/healthy-lifestyle/nutrition-and-healthy-eating/in-depth/water/art-20044256).
- Comparación sencilla de agua, otras bebidas y alimentos con alto contenido de agua.
- Contador diario configurable, con progreso guardado en el dispositivo.
- Horarios predeterminados para recordatorios mientras la página permanezca abierta.

La cantidad adecuada varía entre personas. Este proyecto ofrece información general para adultos saludables y no sustituye el consejo de un profesional de la salud.

Hecho con HTML, CSS y JavaScript; preparado para GitHub Pages.
