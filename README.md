# Agüita 💧

Una web interactiva en español para aprender sobre hidratación y acompañar el hábito de tomar agua, un vaso a la vez.

## Abrir la web

[Visitar Agüita](https://martnmartnez14.github.io/aguita/)

## Qué incluye

- Guía orientativa sobre líquidos diarios, basada en información de [Mayo Clinic](https://www.mayoclinic.org/es/healthy-lifestyle/nutrition-and-healthy-eating/in-depth/water/art-20044256).
- Comparación sencilla de agua, otras bebidas y alimentos con alto contenido de agua.
- Contador diario configurable, con progreso guardado en el dispositivo.
- Horarios predeterminados para recordatorios mientras la página permanezca abierta.

La cantidad adecuada varía entre personas. Este proyecto ofrece información general para adultos saludables y no sustituye el consejo de un profesional de la salud.

Hecho con HTML, CSS y JavaScript; preparado para GitHub Pages.

## Mate, Té y energizantes

Las vistas Mate y Té incluyen tarjetas y desplegables nativos, con referencias junto a la información. Sin JavaScript se muestran las tres vistas y los desplegables siguen funcionando. El contador y sus metas corresponden únicamente a Agua.

Fuentes revisadas el 20 de octubre de 2026:
- [EFSA: cafeína](https://www.efsa.europa.eu/es/topics/topic/caffeine): referencias para adultos y embarazo, variabilidad y sueño.
- [IARC: bebidas muy calientes](https://www.iarc.who.int/media-centre-iarc-news-drinking-very-hot-beverages/): clasificación y temperatura; 65 °C no se presenta como garantía de seguridad.
- [JND: energizantes](https://www.gub.uy/junta-nacional-drogas/comunicacion/publicaciones/energizantes): efecto estimulante, precauciones, niñez y alcohol.
- [Estudio de preparación del mate, 2024](https://pubmed.ncbi.nlm.nih.gov/38893465/): cafeína, polifenoles y variaciones de extracción; sin adoptar recomendaciones de consumo del artículo.
- [Ensayo de mate, 2025](https://onlinelibrary.wiley.com/doi/10.1002/mnfr.70065): resultados exploratorios en indicadores, sin inferir prevención clínica.
- [NCCIH: té verde](https://www.nccih.nih.gov/health/green-tea): planta, evidencia limitada, diferencias entre bebida y suplementos, precauciones e interacciones.

Los textos aportados se usaron como material inicial, no como evidencia validada. No se incorporaron estadísticas, dosis terapéuticas, equivalencias por lata ni propuestas legales. La información no fue revisada por un profesional clínico.
